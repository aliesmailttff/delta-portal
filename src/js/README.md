# فهرس مراجعة كود البوابة

> عدّل ملفات هذا المجلد فقط. لا تعدّل `public/js/app.js` لأنه ملف تشغيل مُولّد تلقائياً من هذه الملفات عند تنفيذ `npm run build`.

## ترتيب الملفات

الملفات تُجمع رقمياً؛ لذلك يبقى كل ملف في نفس النطاق البرمجي ويمكنه استخدام الدوال والمتغيرات التي عرّفتها الملفات السابقة.

| الملف | وظيفته | متى تعدّله؟ |
|---|---|---|
| `01-core-state.js` | إعداد Firebase، حالة المستخدم، الدوال العامة والحماية الأساسية. | مشكلة اتصال أو صلاحيات عامة أو حالة الجلسة. |
| `02-auth-data-nav.js` | تسجيل الدخول، تحميل البيانات، التنقل والقائمة الجانبية. | مشكلة دخول أو تاب أو تحميل بيانات. |
| `03-views.js` | واجهات التابات ومحتوى الشاشات. | تغيير شكل/محتوى شاشة أو تاب. |
| `04-students-idcard.js` | قائمة الطلاب، البحث، وكارنيه الطالب. | بيانات الطالب أو صورة/طباعة الكارنيه. |
| `05-chart-bindforms.js` | الرسوم البيانية وربط النماذج بأحداث الحفظ. | رسم بياني أو زر حفظ في نموذج. |
| `06-payments.js` | المصروفات، المدفوعات، الاعتماد والتعديل والحذف. | مشكلة عملية دفع أو كشف مالي. |
| `07-admin-actions.js` | إجراءات الإدارة: إنشاء حسابات، نتائج، حضور. | إضافة/تعديل طالب أو إجراء إداري. |
| `08-print-edit-chat.js` | الطباعة، النوافذ المنبثقة، التعديل والمحادثات. | مشكلة رسالة أو طباعة أو تحرير سجل. |
| `09-security-ux.js` | تغيير كلمة المرور الإجباري، الخمول، الاتصال والتقويم. | أمن الحساب أو تجربة استخدام عامة. |
| `10-schedule-requests.js` | جدول المحاضرات والطلبات الإلكترونية. | جدول أو طلب طالب أو رد عليه. |
| `11-results-gpa.js` | النتائج، المعدل التراكمي، رفع Excel وكشف الدرجات. | نتيجة أو GPA أو استيراد درجات. |
| `12-courses-registration.js` | المقررات وتسجيل الطالب فيها. | مادة أو تسجيل مقرر. |
| `13-admin-tools.js` | أدوات الإدارة: الاستيراد، الصيانة، QR والبحث. | استيراد طلاب أو صيانة أو حضور QR. |
| `14-student-dashboard.js` | لوحة الطالب المختصرة والتنبيهات. | بطاقات وإحصاءات الطالب. |
| `15-attendance-summary.js` | ملخص الحضور والتصدير. | كشف أو تقرير حضور. |
| `16-upgrades.js` | تصدير التقارير وإدارة صلاحيات المساعدين. | صلاحية موظف أو تصدير PDF/Excel. |
| `17-workflows.js` | الإشعارات وتوجيه المحادثات. | تنبيه أو سير عمل الرسائل. |

## ملفات مهمة خارج هذا المجلد

| الملف | وظيفته |
|---|---|
| `public/index.html` | هيكل الصفحة وعناصر الواجهة. |
| `public/css/app.css` | جميع تنسيقات الموقع والتجاوب مع الهاتف. |
| `firestore.rules` | صلاحيات القراءة والكتابة في Firestore. |
| `functions/index.js` | وظائف Firebase الخلفية الاختيارية. |
| `build.mjs` | يجمع ملفات `src/js` وينسخ واجهة الإدارة المستقلة. |

## دورة التعديل الآمنة

1. افتح الملف المختص بالمشكلة وعدّله.
2. نفّذ `npm.cmd run build` من مجلد المشروع.
3. جرّب الموقع محلياً أو على Firebase Hosting.
4. نفّذ `git diff --check` ثم أضف التعديل إلى Git.
5. إذا تغيرت صلاحيات البيانات، انشر أيضاً `firestore.rules`.

## قاعدة مهمة

لا تنسخ دالة إلى ملف آخر قبل البحث عن اسمها أولاً. استخدم:

```powershell
rg "اسم_الدالة" src/js
```

بهذا تعرف موضع تعريفها وكل الأماكن التي تستخدمها قبل تعديلها.
