# نشر بوابة معهد الدلتا على Firebase

من داخل مجلد المشروع (اللي فيه firebase.json):

    npm i -g firebase-tools
    firebase login
    firebase use delta-student-portal
    firebase deploy --only firestore:rules,hosting

الموقع هيبقى على: https://delta-student-portal.web.app

## بعد أول نشر
1. من Authentication فعّل Email/Password، ومن Settings > Authorized domains تأكد إن دومين الموقع موجود.
2. ادخل كأدمن > تاب "الحسابات والصيانة" واكتب أرقام الدفع الحقيقية (مفيش أرقام افتراضية).
3. جرّب بحساب طالب وحساب مالي وحساب أكاديمي (قواعد Firestore اتكتبت من غير emulator، اختبرها في Rules Playground).
4. من Google Cloud > APIs & Services > Credentials قيّد الـ API key على دومين موقعك.
5. التطبيق: افتح الموقع على الموبايل واختار "إضافة إلى الشاشة الرئيسية".

## ملاحظة أمنية مهمة
النسخة السابقة كانت بتخزّن كلمة مرور الطالب كنص عادي في Firestore وبتعرضها في بطاقة الطالب. الكود الجديد وقف ده،
وأول ما أدمن أو أكاديمي يفتح التطبيق بتتمسح تلقائياً أي كلمات مرور مخزنة من ملفات الطلاب.
الطلاب الجدد بيتطلب منهم تغيير كلمة المرور المؤقتة عند أول دخول. الطلاب القدام لازم يعملوا "نسيت كلمة المرور" أو تبلّغهم بتغييرها لأن كلمات مرورهم القديمة اتكشفت لموظفين.
