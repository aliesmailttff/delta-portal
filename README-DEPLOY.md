# نشر بوابة معهد الدلتا على Firebase

من داخل مجلد المشروع (اللي فيه firebase.json):

    npm i -g firebase-tools
    firebase login
    firebase use delta-student-portal
    firebase deploy --only functions,firestore:rules,firestore:indexes,hosting

الموقع هيبقى على: https://delta-student-portal.web.app

## بعد أول نشر
1. من Authentication فعّل Email/Password، ومن Settings > Authorized domains تأكد إن دومين الموقع موجود.
2. ادخل كأدمن > تاب "الحسابات والصيانة" واكتب أرقام الدفع الحقيقية (مفيش أرقام افتراضية).
3. جرّب بحساب طالب وحساب مالي وحساب أكاديمي (قواعد Firestore اتكتبت من غير emulator، اختبرها في Rules Playground).
4. من Google Cloud > APIs & Services > Credentials قيّد الـ API key على دومين موقعك.
5. التطبيق: افتح الموقع على الموبايل واختار "إضافة إلى الشاشة الرئيسية".

## وظائف الإدارة والحضور
إعادة تعيين كلمة مرور الطالب، حذف المحادثة للطرفين، ورموز QR المتغيرة تعتمد على Cloud Functions. تتضمن الدوال أيضًا إشعارات تغيير الطلبات والنتائج والمدفوعات والجدول، وتذكيرًا شهريًا بالمصروفات، وتنبيهًا للغياب بعد إغلاق المحاضرات. يلزم تفعيل خطة Blaze وربط حساب فوترة لنشر Cloud Functions والمهام المجدولة؛ قد تترتب رسوم حسب الاستخدام. وضع صيانة الطلاب يُدار من تبويب الحسابات، بينما وضع صيانة الدفع منفصل.

## سير الطلبات والمحادثات والجدول
- الطلب الأكاديمي يراجعه المساعد الأكاديمي ثم يحيله لاعتماد المدير، والطلب المالي يذهب للمساعد المالي أو المدير.
- المساعد الأكاديمي يضيف المحاضرة كمسودة اعتماد، والمدير ينشرها للطلاب. المحاضرات القديمة تحتاج اختيار «نشر الجدول القديم» من تبويب الجدول مرة واحدة.
- المدير يستطيع توجيه محادثة لقسم ومساعد محددين. يستطيع المساعد المعيّن أو فريق القسم الوصول إليها.
- التنبيهات تظهر داخل تبويب «التنبيهات» للطالب؛ لا تتطلب إشعارات المتصفح.

في PowerShell على Windows استخدم `npx.cmd` لتفادي منع تشغيل `npx.ps1`:

    cd "C:\Users\blackhorse\Desktop\delta-portal"
    npm.cmd run build
    npx.cmd firebase-tools login
    npx.cmd firebase-tools deploy --only functions,firestore:rules,firestore:indexes,hosting --project delta-student-portal

## ملاحظة أمنية مهمة
النسخة السابقة كانت بتخزّن كلمة مرور الطالب كنص عادي في Firestore وبتعرضها في بطاقة الطالب. الكود الجديد وقف ده،
وأول ما أدمن أو أكاديمي يفتح التطبيق بتتمسح تلقائياً أي كلمات مرور مخزنة من ملفات الطلاب.
الطلاب الجدد بيتطلب منهم تغيير كلمة المرور المؤقتة عند أول دخول. الطلاب القدام لازم يعملوا "نسيت كلمة المرور" أو تبلّغهم بتغييرها لأن كلمات مرورهم القديمة اتكشفت لموظفين.
