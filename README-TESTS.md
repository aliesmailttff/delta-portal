# اختبار قواعد Firestore

المطلوب: Node 18+ و Java (الـ emulator بيحتاجه).

    npm install
    npm test

الأمر بيشغّل Firestore Emulator ويجرّب القواعد بحسابات (أدمن، مالي، أكاديمي، طالبين). أي اختبار يفشل معناه إن القاعدة
بتسمح بحاجة ممنوعة أو بتمنع حاجة لازم تتسمح. شغّله قبل كل `firebase deploy`.
